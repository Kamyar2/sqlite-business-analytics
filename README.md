# Operational SQL Diagnostics & Business Analytics

## Overview
A collection of analytical SQL queries and database diagnostic scripts designed to analyze operational log data, identify system performance bottlenecks, and extract key business metrics from SQLite environments.

## Business Value & Insights
* **Performance Diagnostics:** Identifies high-latency modules and system error trends.
* **Revenue & Volume Tracking:** Calculates aggregated transactional KPIs and average ticket sizes.
* **Funnel Efficiency:** Measures operational conversion rates and status distributions.

## Tech Stack
* **Database:** SQLite / Relational DBs
* **Tooling:** SQLite Browser, SQL Queries
* **Focus Areas:** Data Aggregation, Filtering, Grouping, Diagnostic Metrics

## File Structure
* `analysis_queries.sql`: Practical SQL scripts for diagnostic and reporting queries.
